API Mock 实验台

用这个页面点按钮发请求，然后在 DevTools 里看 API Mock 面板怎么处理它们。

怎么开始

  1. pnpm build
  2. 打开 chrome://extensions → 打开「开发者模式」→「加载已解压的扩展程序」→ 选本项目的 dist/ 目录
  3. 页面装好插件后要刷新一次才会被接管
  4. 按 F12 打开 DevTools，切到 API Mock 面板

默认状态下什么都没被改写，所有按钮都会打出真实响应。想看改写效果，先在面板里建一条规则 （把 URL 模式填成 http://localhost:8787/api/* 最省事），再回来点按钮。
